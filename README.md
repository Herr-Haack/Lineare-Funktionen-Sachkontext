# Lineare Funktionen im Alltag

Interaktives Übungstool für Mathematik Klasse 8 zum Thema lineare Funktionen in Sachkontexten.

## Übungsarten
1. **Funktionswert ablesen** – zu einer gegebenen Stelle x den Funktionswert am Graphen ablesen
2. **Stelle ablesen** – zu einem gegebenen Funktionswert die Stelle x am Graphen bestimmen
3. **Gleichung aufstellen** – aus einer Sachsituation die Funktionsgleichung `f(x) = m · x + n` aufstellen
4. **Gemischt** – alle Übungsarten zufällig

Drei Schwierigkeitsstufen, 12 Sachsituationen mit zufälligen Zahlen, Tipps, Lösungswege mit Probe und Antwortsatz.

## Nutzung
`index.html` im Browser öffnen – keine Installation nötig.
